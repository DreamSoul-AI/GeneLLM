# 低成本检查组选择：数学定义 v1

日期：2026-09-07。状态：问题与数学定义已整理，当前保持稳定。方法与实验设计另见 [独立文档](cost_aware_methods_and_experiments.md)。

**对每个目标疾病，寻找一套获取费用低、能够有效识别该疾病的特征，并训练使用这些特征的模型。** 当前不考虑人群划分或个体化检查选择。同一疾病在部署时使用同一套特征，不同疾病可以选择不同的集合。

“识别该疾病”在本版中指根据合法特征预测是否患有目标疾病。最省钱按已确认的损失与费用权衡定义，不另加未指定的性能门槛，也不将加权最优称为无条件的最低费用。

## 1. 单疾病、共享方案、模型需要学习

固定一个目标疾病 t，学习两个对象：

| 对象 | 含义 |
| --- | --- |
| z_t | 该疾病统一使用的检查购买向量，每个检查只有一个二元开关。 |
| θ_t | 该疾病预测模型的参数，学习所选特征与疾病标签之间的关系。 |

同一疾病的所有受试者共享 z_t，测得的特征值和预测概率可以不同。z_t 不读取个人检查结果来改变方案。训练时可利用合法训练数据评估哪些检查有价值；部署时先确定方案，再获取相应特征并预测。

各疾病可独立求解。本版不要求多任务模型，也不将不同疾病的选择费用合并成一次多疾病就诊账单。

## 2. 从检查得到特征、计算费用

对目标疾病 t，先排除目标标签及禁止使用的泄漏信息：

| 符号 | 含义 |
| --- | --- |
| F_t | 允许使用的特征全集。 |
| F₀,t ⊆ F_t | 决策前已知、确实可免费使用的基础特征。 |
| g = 1,…,m | 实际获取/计费单位，不直接等于医学语义类别。 |
| G_g,t ⊆ F_t | 检查 g 提供的合法特征，可以重叠。 |
| c_g ≥ 0 | 每人、一次目标疾病评估的完整检查费用，使用统一 CNY 或 proxy_unit。 |
| z_tg ∈ {0,1} | 目标疾病 t 的方案是否购买检查 g。 |

给定检查方案，最终可获得的特征集为：

```text
S_t(z_t) = F₀,t ∪ ⋃ G_g,t
                  g: z_tg = 1

Cost(z_t) = Σ_g c_g z_tg
```

这里 S_t 就是希望找到的 feature set，实际费用由获取它的检查方案 z_t 决定。套餐提供的合法特征全部可供模型使用，模型可以忽略其中部分；不是只计算非零系数对应的单个指标价格。

令 A_jg,t=1 表示检查 g 足以获取特征 j，则可用性为：

```text
a_j,t(z_t) = 1{ j ∈ F₀,t，或者 Σ_g A_jg,t z_tg ≥ 1 }
```

同一特征从任意充分路线获取后即可使用；特征去重，但同时购买两项检查仍付两笔费用。需要多个检查共同产生的派生特征，必须加入相应先决条件，不能误写成 OR 覆盖。

费用为 0 不自动等于已知信息，基础集需明确声明。套餐只使用部分指标也支付全价。未包含在选项中的共享采样费和组合折扣需要额外计费规则。

## 3. 模型如何使用所选特征

训练数据记为 D_train,t={(x_i,y_it)}，y_it 表示第 i 人是否患有目标疾病 t。输入处理 T_η 包含填补、编码、缩放及缺失标记，其统计量仅从训练数据拟合。

```text
模型输入：v_i,t(z_t) = T_η(x_i, a_t(z_t))
患病概率：p_it = h_θ_t(v_i,t(z_t))
```

预测器只能使用 S_t(z_t) 内的合法信息。未购买特征的隐藏真值不能通过填补、缩放、编码旁路或模型支路进入预测。若两条记录在所选特征及其实际缺失状态上相同，其他隐藏值的改变不应改变该方案下的预测。

原始数据自身缺失时，可读信息由购买可用性与实际观测状态共同决定；已购买但缺失不自动退费。

θ_t 是需要学习的模型参数，包括模型内可学习的表示层。

## 4. 单疾病的主问题

已确认的损失是平均二元交叉熵（BCE / binary log loss），比较真实患病标签与预测概率。[定义参考](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.log_loss.html)。

```text
单样本损失：
ℓ(y, p) = −y ln(p) − (1−y) ln(1−p)

该疾病的平均预测损失：
R̂_t(θ_t, z_t) = (1/n_t) Σ_i ℓ(y_it, h_θ_t(T_η(x_i,a_t(z_t))))

目标：
最小化 J_t,α(θ_t, z_t)
     = R̂_t(θ_t, z_t) + α · Σ_g c_g z_tg

变量：
θ_t 为可学习的预测模型参数
z_t ∈ {0,1}^m 为该疾病共享的检查方案
```

上式同时将模型参数与检查选择作为优化变量，不指定具体求解方法。

BCE 使用自然对数、样本等权、按样本取平均。费用是每人使用这一套方案的固定费用，不乘训练样本数量。费用单位、损失归一化和 α 需一起记录。

α>0 是效果与费用的取舍参数，具体取值待实验比较。它不是预算上限。若更贵的方案带来的损失下降大于 α 乘新增费用，加权目标可能选择它；较大的 α 也可能使仅基础信息方案胜出。

因此，给定 α 的目标最优表示当前权衡下的最佳方案；它不保证无条件最低费用，也不自动保证某个最低识别水平。启发式算法找到的方案更不能直接宣称是离散全局最优。

## 5. 最终希望输出什么

每个疾病输出：

1. 检查方案 z_t：具体购买哪些检查。
2. 特征集 S_t(z_t)：这些检查提供哪些合法特征。
3. 对应训练好的预测模型 θ_t。
4. 每人的实际检查费用，以及独立测试中的 BCE、AUROC、AUPRC。

例如两套方案能取得完全相同的合法特征，且获取质量与输入表示相同，则它们具有相同的模型输入与可训练模型空间。对 α>0，较便宜的获取方案更优。

首版 feature set 指可供模型使用的合法信息集；若另需裁剪已购买套餐内的冗余指标，可作为后续分析，不改变套餐账单。
