# 最低费用充分检查集：问题与数学定义 v2

确认日期：2026-09-09。本文为当前问题定义，取代 [历史 v1](cost_aware_formulation_v1.md) 中将损失与费用加权和作为研究目标的表述。v1 按原字节保留，仅用于复现历史实验；方法与训练设计另见 [方法文档](cost_aware_methods_and_experiments.md)。

**对每个目标疾病，在完整保留全部合法可获取信息所提供的疾病预测信息的检查方案中，找到每人总费用最低的方案，并训练使用该方案的预测模型。**

目标答案由数据分布、合法可获取信息、检查覆盖和价格共同决定，不随算法超参数变化。不设总费用预算上限，不通过提高费用惩罚把丢失疾病信息的方案重新定义为正确答案。

## 1. 单疾病、共享检查方案与可学习模型

固定疾病 t，标签 Y_t∈{0,1}。同一疾病的所有受试者使用同一套检查方案 z_t，预测模型的参数 θ_t 需要从训练数据学习。z_t 不依据某个人的检查结果临时改变。

当前不考虑人群分层、个体化获取或多疾病合并账单。不同疾病分别求解；本文定义观察信息与疾病标签的预测关系，不要求识别致病原因。

## 2. 合法信息、检查覆盖与实际收费

| 符号 | 含义 |
| --- | --- |
| F₀,t | 决策前实际已知且可免费使用的基础特征。 |
| G_g,t | 检查 g 提供的合法特征，允许不同检查重叠。 |
| F_t | 排除标签泄漏后，全部合法可获取特征，即 F₀,t 与所有 G_g,t 的并集。 |
| c_g≥0 | 每人、一次目标疾病评估购买检查 g 的完整费用，统一使用 CNY 或 proxy_unit。 |
| z_tg∈{0,1} | 是否购买检查 g；z_t 为整套购买方案。 |
| Z_t | 满足检查先决条件的可行购买方案集合；全部检查方案 z_all 可行。 |

```text
取得的特征集：S_t(z_t) = F₀,t ∪ ⋃_{g:z_tg=1} G_g,t
每人实际费用：Cost(z_t) = Σ_g c_g z_tg
```

上述并集适用于各 G_g,t 中的特征可由检查 g 单独充分获取的情况。需要多项检查共同产生的派生特征，改用满足全部先决条件的可用性规则来定义 S_t(z)，不能把它作为单检查足以提供的指标直接并入。特征去重，但实际同时购买的检查分别收费。套餐只使用一个指标也支付全价。

标价为零不等于信息已经可用；需要额外采集的零价检查仍要计入方案。套餐内冗余指标不增加套餐价格。本版采用固定、可加的费用；采样共享费和组合折扣若要使用，须先显式扩展收费规则。

不同获取路线覆盖同一特征时，本版假定其观测内容与质量相同；质量不同的路线需要分别表示其可获得的信息，不能只按同名指标合并。

## 3. 什么叫完整保留疾病预测信息

O_t(z) 表示购买方案 z 后实际能观察到的信息，包括相应特征值及实际缺失状态；O_t,all 表示购买全部合法检查后可观察到的信息。固定方案下，O_t(z) 可从 O_t,all 中提取。潜在但实际未观测到的真值不属于 O_t,all。

“完整”相对于本研究声明的合法可获取信息全集，不是指所有可能存在的生物学信息，也不意味着疾病标签没有随机噪声。

定义两种真实条件患病概率：

```text
全部信息下：p_t,all = P(Y_t=1 | O_t,all)
所选信息下：p_t,z   = P(Y_t=1 | O_t(z))

方案 z 充分，当且仅当：
p_t,z = p_t,all    （以概率 1 成立）
```

这表示：已知所选检查后，再获得其余合法检查，不会改变对疾病的真实条件概率判断。对二分类标签，它等价于条件独立关系：

```text
Y_t ⟂ O_t,all | O_t(z)
```

这是预测信息的充分性，不是要求模型对每位受试者都分类正确。即使掌握全部有效信息，标签仍可能随机。[条件独立与特征充分性的研究背景](https://proceedings.mlr.press/v124/yang20b.html)。

## 4. 最低费用充分检查集

先定义保留全部预测信息的可行集合，再在其中最小化费用：

```text
Z_t,suff = { z∈Z_t : p_t,z = p_t,all，几乎处处成立 }

C_t* = min_{z∈Z_t,suff} Cost(z)

Z_t* = { z∈Z_t,suff : Cost(z)=C_t* }
```

Z_t* 是最优方案集合，允许存在多套同价、同样充分的方案。算法找到其中任何一套均可算成功；不强制任意指定的一套唯一 GT，也不把最少检查数量或最少特征数量替代最低费用。

因为全检查方案属于 Z_t,suff，且可行检查组合有限，当前设定下最优方案存在。价格为零时可以有包含额外零价检查的同价最优方案；不额外引入数量最小化的次级目标。

这一目标中没有 α，也没有预算 B。模型或超参数改变，可以改变算法找到的结果，但不能改变由本节定义的正确答案。

## 5. 与 BCE 的关系

继续使用二元交叉熵衡量概率预测。它在这里用于表达预测信息是否损失，以及训练和评价模型，不与费用组成最终研究目标。

```text
ℓ(y,p) = −y ln(p) − (1−y) ln(1−p)

给定方案的理想最优预测风险：
R_t*(z) = inf_q E[ℓ(Y_t, q(O_t(z)))]
        = E[ℓ(Y_t, p_t,z)]

信息损失：Δ_t(z) = R_t*(z) − R_t*(z_all) ≥ 0

等价的主问题：
最小化 Cost(z)，条件为 z∈Z_t 且 Δ_t(z)=0。
```

这里 inf_q 遍历基于所选观测的所有可测概率预测函数，并非限制在某个有限网络架构。对自然对数 BCE，条件期望计算给出：

```text
Δ_t(z) = E[ KL(Bernoulli(p_t,all) || Bernoulli(p_t,z)) ]
```

因此 Δ_t(z)=0 与第 3 节的充分性等价。该关系来自对数评分的严格适当性及所选信息包含于全部信息这一前提；这里将其用于我们的检查成本定义。[对数评分与严格适当性](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)。

经验 BCE、某次模型训练的最小损失或相同 AUROC，不能直接替代总体层面的 Δ_t(z)=0。有限样本的误差、模型表达限制和训练未收敛，都可能使这些量不同。

## 6. 模型学习与数据边界

完成特征获取后，预测器只能使用 O_t(z) 中的信息。填补、编码、缩放和缺失标记处理的统计量只从训练数据拟合；未购买真值不能通过预处理、旁路或其他模型支路进入预测。

```text
模型输入：v_i,t = T_η(O_i,t(z))
预测概率：p̂_i,t = h_θ_t(v_i,t)
训练损失：R̂_t(θ_t,z) = (1/n_t) Σ_i ℓ(y_i,t,p̂_i,t)
```

θ_t 与必要的处理参数从数据中学习，用于估计所选方案下的条件概率。选择正确检查集合和训练好预测器是两个都需要评价的结果；正确集合不保证某次训练已经得到优秀预测器，优秀测试分数也不自动证明集合充分或费用最优。

## 7. GT 与当前合成任务

当前合成实验中，20 个输入相互独立，生成概率分别为 sigmoid(1.7×x2−1.3×x5) 和 sigmoid(4×x2×x5)。两种机制都非平凡地依赖 x2、x5；遗漏任一个时，其余独立变量无法还原完整条件概率。因此 {x2,x5} 是保留生成概率所需的最小特征集合。

两项特征分别只能由 g0、g1 获取，价格为 10、20，其他检查价格均为正。因此两个任务的最优方案唯一：

```text
Z_t* = {购买 g0 和 g1 的方案}
C_t* = 30 proxy_unit
```

实际购买两个套餐会取得 6 个指标；其中只有 x2、x5 携带生成信号。不能把套餐附带的无关指标误算为额外购买检查或额外收费。

| 算法结果 | 固定 GT 下的含义 |
| --- | --- |
| g0＋g1，费用 30 | 充分且费用最低，恢复 GT。 |
| 遗漏 g0 或 g1 | 不充分；更便宜不能补偿这一失败。 |
| g0＋g1＋额外正价检查 | 充分但费用非最优，存在额外开销。 |
| 不购买付费检查，费用 0 | 此例中不充分，不是另一种正确答案。 |

真实数据未必有可直接观察的 GT；多个替代特征或获取路线也可能产生多套最优方案。生成器中的变量名单只有经过充分性和费用核对，才能用作检查方案 GT。

## 8. 最终输出与文档边界

每个疾病输出检查方案、取得的合法特征集、训练好的预测模型、每人账单，以及独立测试中的 BCE、AUROC 和 AP。GT 已知的合成实验还评价最优方案恢复、信息遗漏和充分条件下的额外费用；不能仅凭高预测分数宣布完成选组目标。

本文不规定具体求解器、正则化形式、超参数调节或有限样本充分性检验流程。方法参数只能影响求解过程，不能重定义 Z_t*。实际数据中如何估计信息损失、处理统计不确定性，以及设置近似判据，在方法文档中另行设计；未在此悄然加入一个已确定的性能容差。
