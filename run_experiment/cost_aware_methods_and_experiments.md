# Group Lasso：方法与实验设计

日期：2026-09-07。本文只描述本分支包含的 Group Lasso 工作；研究目标沿用 [问题与数学定义](cost_aware_formulation_v1.md)。数学定义文件保留原始内容。

## 1. 当前方法

采用非重叠检查组的 logistic Group Lasso，同时学习预测系数和组稀疏结构。截距不惩罚；免费基础特征不受组惩罚。拟合的代理目标为：

```text
平均 BCE + λ Σ_g sqrt(|G_g|) ‖β_g‖₂ + γ ‖β‖₂² / 2
```

λ 控制组稀疏性，γ=1e-4 是固定 ridge 正则化；组范数不等于实际检查费用。求解器采用近端梯度和组 L2 近端算子，使用 logistic Hessian 的全局上界确定步长，通过 KKT 残差检查停止。[组稀疏定义参考](https://icml.cc/Conferences/2009/papers/471.pdf)。

输入检查拒绝重叠组、非有限数值和缺少二分类标签的情况。列编码及标准化仅由训练数据确定。

## 2. 从路径得到低成本方案

1. 在训练数据上拟合仅基础信息模型，由其组梯度计算 λ_max。
2. 在 1.05×λ_max 至 0.005×λ_max 的 40 个对数间隔值及 λ=0 上拟合路径。
3. 以组范数超过 1e-6 判定活动组，转为实际检查方案，并加入基础信息和全检查两种边界候选。
4. 各候选统一用训练数据重拟合 ridge logistic，仅输入对应检查能获取的合法特征。
5. 验证数据按 `BCE + α × Cost` 选择方案，所有选择完成后才评价测试数据。

费用参与第 5 步，不参与本轮 Group Lasso 系数拟合。α 与 λ 用途不同；当前算法只搜索路径及边界候选，不保证主问题的全局最优。

## 3. 已完成的合成实验

- 每个任务 3600 条记录；2 个免费特征、6 个付费组各 3 个特征。
- 临时费用依次为 10、20、35、60、90、140，均为 proxy_unit。
- 任务 A 的有效付费组是 g0、g1；任务 B 是 g2、g4；任务 C 只依赖免费信息。
- 使用种子 51966、51967、51968，分别分层划分训练/验证/测试为 60%/20%/20%。
- α 网格为 0、0.00025、0.0005、0.001、0.002、0.005、0.01、0.02；不按测试成绩选 α。
- 枚举全部 64 套检查组合作比较，使用同一批重拟合模型。

模型输出、逐次结果、均值和标准差见 [实验报告](../results/group_lasso_pilot_20260907/report.md)。模型文件保存了缩放参数和样本划分，便于复核。

## 4. 验证与范围

[测试](../tests/test_group_lasso.py)覆盖独立 SciPy 优化器对照、数值差分 KKT、免费特征保留、输入检查、重叠费用核算及验证选择与测试分数的隔离。

本轮不是重叠 Group Lasso 实验。覆盖/计费测试中的重叠例子只验证按实际购买收费，不证明重叠模型已经实现。合成关系为线性 logistic 生成，不能外推真实疾病或非线性互补信号。

后续方法议题为：费用是否直接进入候选生成、显式购买成本与组惩罚的求解关系，以及重叠组扩展。真实数据接入另行开展。
