# 最低费用充分检查集：方法与实验设计

更新日期：2026-09-09。当前研究目标以 [数学定义 v2](cost_aware_formulation_v2.md) 为准：完整保留疾病预测信息，再最小化检查费用。本文描述 MLP＋成本加权 Group Lasso 的代理求解与评价，不将损失费用加权和重新定义为研究目标。

## 1. 研究目标与方法参数分开

正确答案由总体数据分布、合法可获取信息、覆盖关系和价格决定。模型架构、初始化、训练次数或正则强度改变，都不改变最优检查方案集合。α 只是方法参数，不表示可以接受另一套丢失预测信息的 GT，也不是预算上限。

现有实现为了复现保留原参数名：`lambda/group_reg` 控制训练中的组惩罚；历史 `alpha` 控制验证评分 `BCE+alpha×Cost`。二者都是方法设置，没有强行改成同一个数。历史加权评分最低只说明该评分规则选中了它，不构成充分性或最低费用证明。

在当前两个合成任务中，唯一目标始终是 g0＋g1，费用 30。少买任一组是信息遗漏，多买正价无关检查是额外开销；高 AUROC 或低费用都不能单独代替任务成功。

## 2. 当前训练模型：MLP＋成本加权 Group Lasso

主预测器采用单隐藏层 tanh MLP，各层共同训练。首个机制配置为 20 个输入 → 24 个隐藏单元 → 一个 logit；概率为 sigmoid(logit)。架构是方法配置，不是已经验证适用于所有疾病的最佳网络。

第一层 W1 按“输入特征 × 隐藏单元”存储。检查 g 对应其全部特征通向全部隐藏单元的连接块 W1[G_g,:]；组惩罚使用这个块的 Frobenius 范数。没有其他输入旁路，整组精确归零后，未购买检查的数值不影响预测。组门控暂缓。

```text
训练代理：平均 BCE(θ) + λ Σ_g w_g ‖W1[G_g,:]‖_F
                       + ridge/2 × (‖W1‖_F² + ‖W2‖₂²)

当前价格权重：w_g = sqrt(|G_g|) × c_g / median(正价格)
无价格对照：  w_g = sqrt(|G_g|)
实际账单：    Σ_g c_g × 1{‖W1[G_g,:]‖_F > 0}
```

这是将价格引入连续组稀疏训练的一种代理，不等价于数学定义中的充分性约束。权重先用归一化的线性价格，是可调整的实验默认值；它不能确保每次训练都会恢复最低费用充分方案。

输入标准化只拟合训练数据；免费基础信息不受付费组惩罚。全部权重矩阵使用 ridge=1e-3，偏置不惩罚，以控制过拟合及跨层参数尺度补偿。第一版限定非重叠检查组；重叠获取路线仍需显式购买与计费设计。

全批量近端梯度先更新平滑损失，再对检查输入块做软阈值；回溯步长保证该次训练代理目标不增加。MLP 整体非凸，驻点指标不是全局最优证明。[输入层稀疏训练参考](https://arxiv.org/abs/1711.07592)。

## 3. 已实现的训练与历史选择流程

[求解器](../medfs/selectors/group_lasso_mlp.py)与 [实验入口](run_group_lasso_mlp_pilot.py)保留已发布配置：

1. 使用训练数据拟合预处理和全输入 MLP；模型参数只从训练数据学习。
2. 从同一个全输入模型，分别开始普通组权重和价格组权重的递增 λ 路径，沿路径承接上一模型。该初始化有助于避免从全零模型出发漏掉纯交互信号。
3. 每次最多训练 1500 步，驻点残差阈值 1e-4；λ∈{0,0.001,0.003,0.01,0.03,0.1}。达到步数上限不能标作收敛。
4. 直接保留 MLP 及其所选检查，不改用 logistic 重拟合；另设免费和全检查边界模型。
5. 历史代码对 α∈{0,0.0005,0.001,0.003,0.01} 使用验证 `BCE+α×实际费用` 选候选，再冻结选择并评价测试集。

第 5 步是已运行的代理选择启发式，不是 v2 的充分性判定或成功标准。保留历史实现和结果以复现；本次没有借助 GT 修改 λ、α、模型参数或历史选择，也没有声称已实现新的有限样本充分性判定。

## 4. 固定 GT 评价

当前两个合成任务的特征相互独立，真实 logit 分别为 1.7×x2−1.3×x5 和 4×x2×x5。根据生成分布，g0、g1 都不可缺少；它们唯一提供信号特征，总费用 30。两个套餐附带的 4 个无关指标不产生额外收费，不算多买检查。

| 评价项 | 定义或解释 |
| --- | --- |
| 最优方案恢复 | 是否选中 g0＋g1；按随机种子统计恢复次数和比例。 |
| 信息充分 | 在本生成器中，是否同时包含 g0、g1；不从拟合分数高低推断。 |
| 漏选 | 必要检查中没有购买的部分。 |
| 多选 | 购买的其他正价检查。 |
| 充分方案的额外费用 | 已保留全部信息时，实际费用减 30；不充分时记为不适用。 |
| 预测器表现 | 单独报告测试 BCE、AUROC、AP，以及训练停止状态。 |
| 候选覆盖 | 已保存的候选中是否存在 GT，仅作诊断，不能拿 GT 替换历史选择。 |

如果其他数据存在等价信息源、多条获取路线或零价检查，应评价是否属于完整最优方案集合；不能机械地要求等于一个任意指定的特征名单。当前 [固定 GT 评价脚本](evaluate_group_lasso_fixed_gt.py)只针对已证明具有唯一答案的两项合成任务，明确拒绝不适用的价格/覆盖配置。

已完成的 [固定 GT 复核](../results/group_lasso_fixed_gt_20260909/report.md)覆盖全部 120 个候选、114 条历史已选结果、38 行参数分组汇总和 18 个候选覆盖记录。它只增加派生评价，不改变原始实验。

沿用此前展示的历史 α=0.001，成本加权 MLP 在线性任务 3/3 次恢复 GT，非线性交互任务 2/3 次恢复；另一次为 g0＋g1＋g2，费用 65，属于充分但费用非最优。不能再仅用平均 AUROC=0.8759、平均费用=41.7 描述为已经找到目标。

不同 α 或 λ 是同一任务的不同方法设置，不是不同 GT，也不是独立重复样本；不把参数网格混合成一个总体成功率。

## 5. 已验证与仍待解决的事项

- 原 MLP 实验为两个任务各 2400 条记录，种子 51966、51967、51968，60%/20%/20% 分层划分；全部是合成数据与临时价格。
- 原 22 项实现测试覆盖梯度数值差分、输入组删除、未购买值不变性、免费信息及 XOR 学习；固定 GT 评价另增加 6 项测试。
- 原模型及收费核验覆盖 120 个候选和 114 条已选方案；72 个 MLP 拟合只有 3 个达到预设驻点阈值，其余达到训练步数上限。全输入 MLP 出现过拟合，不能把它某次拟合的验证损失直接当成全部信息的理想预测上限。
- 仍需设计：如何用训练/验证数据估计信息是否保留、如何处理统计误差、怎样选择正则强度和训练停止条件。若使用近似充分性容差，应作为有限样本方法设置明确说明，不能悄然替代 v2 的精确研究目标。
- 真实疾病、受试者数据和临床检查价格映射尚未接入。无需等待这些数据才能定义问题，但不能宣称当前实验已验证真实疾病的最优方案。
