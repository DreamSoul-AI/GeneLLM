Task: Multiclass classification to predict SARS-CoV-2 variant types (e.g., Alpha, Delta, Gamma) from 1,000-length viral genome sequences. Labels correspond to one of nine major variants (Alpha, Beta, Delta, Eta, Gamma, Iota, Kappa, Lambda, Zeta). The dataset comprises genomes sourced from the GISAID EpiCoV database (Khare et al., 2021), a global repository for coronavirus genomic surveillance. By mapping sequence features to variant identities, models can identify lineage-defining mutations and evolutionary patterns. This task supports public health efforts by enabling rapid variant tracking, vaccine/therapeutic targeting, and analysis of viral adaptation mechanisms.
